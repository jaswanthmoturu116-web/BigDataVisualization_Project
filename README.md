# Big Data Visualization Project

## Overview
This project analyzes supermarket sales data using Python.

The project includes:
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Creation

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dataset
Supermarket Sales Dataset from Kaggle.

## Visualizations
- Bar Charts
- Pie Charts
- Histograms
- Boxplots
- Heatmaps

## Objective
To analyze customer behavior, sales performance, payment methods, and product trends using data visualization techniques.

## Outcome
The project successfully generated business insights through graphical analysis and dashboard visualizations.
